# Vivid Canvas

Build RetailX.site, a world-class high-performance static website builder that rivals Framer in usability, visual quality, and publishing capabilities. The platform should empower creators, agencies, freelancers, startups, and businesses to build beautiful, ultra-fast static websites through an intuitive visual editor while also providing advanced customization for professional developers.

The overall experience should feel premium, modern, and highly interactive with a bold Gen-Z-inspired design language featuring oversized typography, vibrant gradients, high-contrast minimalism, glassmorphism accents, rounded corners, smooth micro-interactions, fluid page transitions, magnetic buttons, premium motion effects, animated backgrounds, and delightful user feedback. Every interaction should feel fast, responsive, and polished.

Implement complete user authentication using Clerk, including email/password authentication, Google sign-in, GitHub sign-in, email verification, password reset, secure session management, user profiles, onboarding, account settings, organization workspaces, team invitations, role-based permissions (Owner, Admin, Editor, Developer, Viewer), billing management, notification preferences, API keys, and activity logs.

Create a beautiful onboarding experience that guides new users through creating their first workspace, selecting a template, customizing branding, and publishing their first website within minutes.

Build a modern dashboard displaying recent projects, favorite templates, deployment history, analytics overview, AI activity, workspace usage, notifications, quick actions, team activity, recent edits, and search functionality.

Develop a complete workspace architecture where every project includes pages, reusable components, global styles, assets, CMS collections, forms, SEO settings, analytics, custom domains, publishing settings, deployment history, backups, custom code, redirects, robots.txt, sitemap generation, environment variables, version history, and collaboration tools.

Create a professional visual builder inspired by Framer with an infinite canvas supporting zoom, pan, snapping, smart guides, rulers, responsive breakpoints, drag-and-drop editing, auto-layout, Flexbox, Grid layouts, absolute positioning, reusable components, variants, symbols, constraints, spacing controls, alignment tools, grouping, locking, visibility toggles, duplication, copy and paste, multi-selection, keyboard shortcuts, undo and redo history, autosave, and real-time editing.

The workspace should include a collapsible left sidebar containing Pages, Layers, Assets, Components, CMS, Variables, Styles, Plugins, AI Assistant, Team, History, Search, and Project Settings. The right sidebar should dynamically display contextual editing controls for layout, spacing, typography, colors, borders, shadows, effects, animations, interactions, responsive visibility, accessibility, SEO, and advanced styling.

Build a comprehensive design system with editable global variables including colors, typography, spacing, shadows, border radius, gradients, animations, icons, breakpoints, reusable tokens, themes, and global styles. Changes should instantly update every connected component across the project.

Develop an extensive drag-and-drop component library including Hero Sections, Navigation Bars, Footers, Pricing Tables, Testimonials, FAQs, Contact Forms, Feature Sections, Team Sections, Statistics Blocks, Timelines, Dashboards, Cards, Buttons, Accordions, Tabs, Drawers, Modals, Sliders, Carousels, Galleries, Video Sections, Maps, Tables, Charts, Login Pages, Newsletter Blocks, Cookie Banners, Popups, Countdown Timers, Ecommerce Sections, Portfolio Layouts, Blog Layouts, and reusable layout primitives.

Create a professional template marketplace featuring hundreds of customizable templates across Startup, SaaS, Agency, Ecommerce, Fashion, Restaurant, Hotel, Healthcare, Education, Architecture, Construction, Real Estate, Photography, AI Startup, Crypto, Personal Portfolio, Landing Page, Consulting, Events, and Nonprofit categories. Each template should include responsive previews, dark mode, SEO score, accessibility score, performance score, animation previews, CMS compatibility, and one-click duplication.

Implement a powerful CMS with customizable collections, dynamic fields, references, media uploads, rich text editing, slugs, categories, filtering, sorting, pagination, search, localization, scheduled publishing, draft mode, version history, and automatic dynamic page generation.

Develop an advanced asset manager supporting folders, drag-and-drop uploads, image optimization, SVG management, video uploads, PDF storage, search, tags, duplicate detection, version history, compression, cloud storage, and CDN delivery.

Create a sophisticated animation engine supporting entrance animations, hover animations, scroll animations, page transitions, timeline animations, interaction triggers, cursor effects, parallax, stagger animations, morphing, easing controls, reusable animation presets, looping animations, and spring-based motion.

Implement a visual interaction builder allowing creators to define click, hover, scroll, viewport, drag, keyboard, timer, and form submission triggers with actions such as navigation, animations, state changes, API requests, conditional logic, variable updates, visibility toggles, and chained workflows without writing code.

Provide advanced responsive editing with Desktop, Laptop, Tablet, Mobile, and custom breakpoints, including responsive typography, responsive spacing, responsive layouts, breakpoint-specific visibility, and live device previews.

Build a complete forms system supporting contact forms, lead generation, newsletter subscriptions, file uploads, validation, spam protection, success pages, email notifications, webhooks, CRM integrations, submission management, and analytics.

Integrate AI-powered tools capable of generating complete websites from prompts, creating new sections, writing website copy, generating layouts, suggesting images, improving accessibility, optimizing SEO, recommending color palettes, generating components, assisting with custom code, and analyzing design quality.

Support advanced custom code integration by allowing users to add custom HTML, CSS, JavaScript, reusable code blocks, external scripts, API integrations, environment variables, custom components, and embedded widgets while maintaining a seamless visual editing experience.

Implement a professional publishing system supporting one-click deployment, preview deployments, instant publishing, custom domains, SSL configuration, CDN delivery, deployment logs, redirects, headers, sitemap generation, robots.txt management, Open Graph metadata, favicon management, rollback support, and exportable static builds.

Create an analytics dashboard displaying visitors, page views, conversion funnels, form submissions, website performance, Core Web Vitals, engagement metrics, traffic sources, search performance, deployment statistics, and growth trends while supporting integrations with major analytics providers.

Implement a complete SEO suite including page titles, descriptions, canonical URLs, structured data, Open Graph metadata, Twitter Cards, schema markup, automatic sitemap generation, robots.txt editing, image alt validation, SEO recommendations, and SEO scoring.

Build a marketplace architecture for templates, plugins, integrations, icon packs, animation libraries, premium UI kits, reusable components, and future third-party extensions.

Implement subscription management with Free, Pro, Business, and Enterprise plans, workspace limits, usage tracking, invoices, coupons, trials, team billing, feature gating, and seamless upgrade flows.

Ensure enterprise-grade security, permission management, audit logs, validation, data protection, secure file handling, abuse prevention, and scalable multi-workspace architecture.

The entire platform must be fully functional, production-ready, responsive across all devices, accessible, optimized for speed, intuitive for beginners, powerful for professionals, and designed with exceptional attention to detail. Every button, form, workflow, editor action, animation, and publishing feature should be fully implemented rather than mocked. The final product should feel like a premium commercial SaaS platform capable of competing directly with Framer while delivering an even more expressive, creator-first website building experience.
